# Асистент доведення семантичної коректності

Опис модуля `sipl.semantics.verifier`: умови VC1-VC4 і межі перевірки.

## 1. Теоретична модель: метод індуктивних тверджень

Для програм із циклом вигляду:
```pascal
init;
while B do
  body;
suffix
```
доведення часткової та повної коректності з передумовою $P$ та постумовою $Q$ зводиться до пошуку інваріанта циклу $Inv$ та функції завершення $V$.

Генеруються чотири верифікаційні умови VC:

1. **VC1, ініціалізація:**
   `P & init => Inv`
   Якщо передумова P виконується на початковому стані, то після виконання операторів ініціалізації стан задовольняє інваріант Inv.

2. **VC2, інваріантність:**
   `Inv & B => Inv[x -> body(x)]`
   Якщо перед входом в ітерацію інваріант Inv та умова циклу B істинні, то після виконання тіла циклу інваріант залишається істинним для нового стану.

3. **VC3, постумова:**
   `Inv & not B => Q[x -> suffix(x)]`
   Якщо інваріант Inv істинний, а умова циклу хибна, то після виконання суфікса гарантується досягнення цільової постумови Q.

4. **VC4, завершення:**
   `V(st) > 0 & V(body(st)) < V(st)`
   Значення цілочисельної функції V строго додатне під час виконання циклу і строго зменшується з кожною ітерацією, що доводить скінченність роботи циклу.

## 2. Обмеження

1. Станів перебираються з областей `domains` зі `.spec.json`. Це перевірка на скінченній області.
2. Якщо знайдено стан, де VC порушується, це справжній контрприклад: інваріант або програма некоректні.
3. Якщо контрприкладів немає, це не доведення для всіх цілих чисел, а лише перевірка в заданих областях.
4. Підтримуються програми виду `init; while B do body; suffix` з одним циклом `while` на верхньому рівні. В інших випадках виводиться повідомлення про помилку.
5. У формулах доступні функції `fact`, `dfact`, `pow`, `gcd`, `fib`, `isqrt`.
6. Перед перевіркою валідується специфікація:
   - усі змінні програми та формул оголошені в `domains`;
   - `pre` залежить лише від `inputs`;
   - якщо для умови перевірено 0 станів, вона отримує статус `[FAIL]`;
   - якщо `variant` не заданий, VC4 пропускається.

## 3. Формат файлу специфікації

```json
{
  "inputs": ["N"],
  "pre": "N > 0",
  "invariant": "R * dfact(2 * N) == dfact(2 * N0)",
  "post": "R == dfact(2 * N0)",
  "variant": "N",
  "domains": {
    "N": [0, 4],
    "N0": [1, 4],
    "R": [1, 384]
  },
  "ghosts": {
    "N0": "N"
  }
}
```

- `inputs`: вхідні змінні програми.
- `pre`: передумова на вхідні змінні.
- `invariant`: інваріант циклу. Доступні функції `fact`, `dfact`, `pow`, `gcd`, `fib`, `isqrt`.
- `post`: результуюча постумова.
- `variant`: цілочисельний лічильник завершення циклу.
- `domains`: інтервали пошуку для кожної змінної `[min, max]`.
- `ghosts`: допоміжні змінні, що фіксують початкові значення входів.
