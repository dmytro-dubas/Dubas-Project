# Формальна семантика мови SIPL

Правила побудови та обчислення семантичних термів у `sipl.semantics` за матеріалами практикуму О.В. Шишацької, А.В. Криволап, А.В. Шишацького.

## 1. Базові математичні поняття

- **Стан програми $st$**: часткове відображення множини змінних у множину цілих чисел:
  `st: Var -> Z`
  Позначення зміни значення змінної $x$ на $v$:
  `st \nabla [x -> v]`
- **Деномінація змінної $x=>$**: семантична функція, яка за станом $st$ повертає поточне значення змінної $x$:
  `x=>(st) = st(x)`
- **Константа**: функція, що для будь-якого стану повертає фіксоване значення:
  `c(st) = c`
- **Суперпозиція операцій $S^2$, $S^1$**:
  `S^2(op, f_1, f_2)(st) = op(f_1(st), f_2(st))`
  `S^1(neg, f)(st) = not f(st)`

## 2. Правила рекурсивної побудови семантичного терму, група NS

Кожен синтаксичний вузол програми перетворюється на відповідний семантичний терм за наступними правилами:

### 2.1. Оператори програми

- `NS_Prog`: `begin S end` -> `sem_S(S)`
- `NS_Stm_Seq`: `S1 ; S2` -> `sem_S(S1) * sem_S(S2)`
- `NS_Stm_As`: `x := a` -> `AS_x(sem_A(a))`
- `NS_Stm_If`: `if b then S1 else S2` -> `IF(sem_B(b), sem_S(S1), sem_S(S2))`
- `NS_Stm_Wh`: `while b do S` -> `WH(sem_B(b), sem_S(S))`
- `NS_Stm_BE`: `begin S end` -> `sem_S(S)`
- `NS_Stm_Sk`: `skip` -> `ID`

### 2.2. Арифметичні вирази

- `NS_A_Num`: `n` -> `n`
- `NS_A_Var`: `x` -> `x=>`
- `NS_A_Add`: `a1 + a2` -> `S^2(add, sem_A(a1), sem_A(a2))`
- `NS_A_Sub`: `a1 - a2` -> `S^2(sub, sem_A(a1), sem_A(a2))`
- `NS_A_Mult`: `a1 * a2` -> `S^2(mult, sem_A(a1), sem_A(a2))`

### 2.3. Булеві умови

- `NS_B_True`: `true` -> `true`
- `NS_B_False`: `false` -> `false`
- `NS_B_Rel`: `a1 op a2` -> `S^2(op, sem_A(a1), sem_A(a2))`, де `op` належить `{eq, gr, ls, ge, le}`
- `NS_B_Neg`: `not b` -> `S^1(neg, sem_B(b))`
- `NS_B_And`: `b1 and b2` -> `S^2(and, sem_B(b1), sem_B(b2))`
- `NS_B_Or`: `b1 or b2` -> `S^2(or, sem_B(b1), sem_B(b2))`

## 3. Правила застосування семантичних функцій до станів, група AF

Під час виконання команди `sipl eval` рушій покроково застосовує правила групи `AF`:

1. `AF_ID`:
   `ID(st) = st`
2. `AF_AS`:
   `AS_x(f_a)(st) = st \nabla [x -> f_a(st)]`
3. `AF_SEQ`:
   `(f_S1 * f_S2)(st) = f_S2(f_S1(st))`
4. `AF_IF_TRUE` / `AF_IF_FALSE`:
   `IF(f_b, f_S1, f_S2)(st) = f_S1(st)`, якщо `f_b(st) = true`
   `IF(f_b, f_S1, f_S2)(st) = f_S2(st)`, якщо `f_b(st) = false`
5. `AF_WH_TRUE` / `AF_WH_FALSE`:
   Обчислення фіксованої точки циклу: якщо умова істинна, стан модифікується тілом циклу і перевіряється наступна ітерація; якщо хибна, цикл завершується з поточним станом.

## 4. Порядок виконання

1. Текст програми розбирається в AST модулем `sipl.parser`.
2. AST перетворюється на семантичний терм модулем `sipl.semantics.builder`.
3. Терм обчислюється над станом за правилами `AF_*` модулем `sipl.semantics.evaluator`.

Виконання йде через семантичний терм, а не напряму по AST, щоб кроки відповідали формулам практикуму.
